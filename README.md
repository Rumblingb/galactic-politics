# Galactic Politics 🪐

A swipe-based political strategy game built with Expo and React Native.

Swipe left or right on politicians to shape the galaxy. Build your cabinet, manage crises, and navigate political intrigue.

## Tech Stack
- **Expo** (React Native)
- **TypeScript**
- **React Navigation**
- **Reanimated** for smooth swipe gestures

## Features
- 🃏 Swipe-deck mechanic for political decisions
- 🌍 Multi-region politician database
- 🎮 Game state management with provider pattern
- 📊 Stats and reporting
- 🔔 Haptic feedback
- 🌓 Dark/light theme support

## Getting Started

```bash
npm install
npx expo start
```
